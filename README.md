# CNSS · Core Nursing Skills Simulator

간호술기를 직접 연습하는 Windows용 시뮬레이터입니다.

## 0.2 베타 다운로드

**[Windows 64비트 게임 다운로드](https://github.com/itsmemanright/CNSS/releases/download/v0.2/CNSS-0.2-Windows-x64.zip)**

[버전 설명과 다운로드 파일](https://github.com/itsmemanright/CNSS/releases/tag/v0.2)

1. 위 링크에서 ZIP 파일을 받습니다.
2. ZIP 파일 전체를 원하는 폴더에 압축 해제합니다.
3. 압축을 푼 폴더의 **CNSS.exe**를 실행합니다.

Unity 설치는 필요하지 않습니다. `CNSS_Data`, `MonoBleedingEdge`, DLL 파일들을 실행 파일과 같은 폴더에 그대로 두세요.

## 이번 버전

- 핵심간호술 15종의 연습·채점·자유 모드
- 크림 배경과 민트 테두리 UI, 간호술기 책과 기록 확인
- 활력징후 실습의 대상자 자세, 기구 사용, 혈압 청진음과 물품 정리 개선
- 새 활력징후 실습마다 측정값 무작위 생성: 맥박·호흡은 짝수, 혈압은 5mmHg 단위
- 저장된 실습을 이어할 때는 측정값 유지
- 해상도·화면 모드·FPS·배경음악·상호작용 소리 설정

개발 중인 베타 버전입니다. [문제 제보](https://github.com/itsmemanright/CNSS/issues)에 술기 이름과 문제가 생긴 순서를 적어 주세요.

## 조작

| 입력 | 기능 |
| --- | --- |
| WASD / Shift / Space | 이동 / 달리기 / 점프 |
| 마우스 왼쪽 버튼 | 집기·놓기·대화·기본 술기 행동 |
| 마우스 오른쪽 버튼 | 기구 착용·문서 읽기 등 추가 행동 |
| 마우스 휠 클릭 | 프로토콜에 필요한 기구 기능 확인 |
| 마우스 휠 위·아래 | 혈압 감압 속도 조절 |
| 1 / 2 / 3 / 4 | 메뉴 / 프로토콜 / 시계 / 책 |
| 0을 3초간 누르기 | 위치 복구 |

연습 모드에서는 빨간 윤곽선을 따라 진행하세요. 자세한 조작은 게임 안의 안내를 확인하세요.
