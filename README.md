## 0.23 베타 다운로드

**[Windows 64비트 게임 다운로드](https://github.com/itsmemanright/CNSS/releases/download/v0.23/CNSS-0.23-Windows-x64.zip)**

[버전 설명과 다운로드 파일](https://github.com/itsmemanright/CNSS/releases/tag/v0.23)

1. 위 링크에서 ZIP 파일을 받습니다.
2. ZIP 파일 전체를 원하는 폴더에 압축 해제합니다.
3. 압축을 푼 폴더의 **CNSS.exe**를 실행합니다.

Unity 설치는 필요하지 않습니다. `CNSS_Data`, `MonoBleedingEdge`, DLL 파일들을 실행 파일과 같은 폴더에 그대로 두세요.

## 이번 버전

- 의사 오더 태블릿, 포스트잇 형태의 투약기록 카드와 기록지 부착 방식 개선
- 약물 준비 확대 화면과 물품 집기·놓기, 세척·폐기 동작 개선
- 근육주사 삼각근 통일, 환의 노출과 준비물 확인 흐름 보완
- 고막 체온계 모델 및 측정 화면 확인 단계 적용
- F1 메뉴 / F2 프로토콜 / F3 시계 / F4 책으로 조작 변경
- 연습 모드 경과시간 표시, 실전 결과에 소요시간 및 시간 초과 감점 적용
- F1 메뉴에 스폰 위치 복귀 추가, 이어하기 바닥의 임시 소품 문제 수정
- 기록실·휴게실·시청실, 트로피 진열장 및 계단·카트 배치 개선

맥박·호흡은 15초 동안 세고 직접 ×4한 분당 값을 입력합니다.
핵심간호술 15종의 연습·채점·자유 모드를 지원합니다.
선생님 시범 걷기 추가 조정은 다음 작업으로 남아 있습니다.

개발 중인 베타 버전입니다. [문제 제보](https://github.com/itsmemanright/CNSS/issues)에 술기 이름과 문제가 생긴 순서를 적어 주세요.

## 조작

| 입력 | 기능 |
| --- | --- |
| WASD / Shift / Space | 이동 / 달리기 / 점프 |
| 마우스 왼쪽 버튼 | 집기·놓기·대화·기본 술기 행동 |
| 마우스 오른쪽 버튼 | 기구 착용·문서 읽기 등 추가 행동 |
| 마우스 휠 클릭 | 프로토콜에 필요한 기구 기능 확인 |
| 마우스 휠 위·아래 | 혈압 감압 속도 조절 |
| R | 동작·대화 배속 변경 |
| F1 / F2 / F3 / F4 | 메뉴 / 프로토콜 / 시계 / 책 |
| F1 메뉴의 스폰 위치로 돌아가기 | 끼임·월드 밖 이탈 시 위치 복귀 |

연습 모드에서는 빨간 윤곽선을 따라 진행하세요. 자세한 조작은 게임 안의 안내를 확인하세요.
