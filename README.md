# CNSS

**Core Nursing Skills Simulator** · 핵심간호술기 연습 게임

학교 실습실에서 물품 준비, 대상자 확인, 술기 수행과 기록을 연습합니다. 안내를 따라 연습하고 수행 결과와 진행도를 확인할 수 있습니다.

위 최신 다운로드 주소는 다음 버전에서도 그대로 사용할 수 있습니다. [이전 버전](https://github.com/itsmemanright/CNSS/releases)도 남겨 둡니다. 이 저장소는 실행 파일과 이용 안내를 배포하는 곳입니다.

## 설치와 실행

### Windows

1. Windows ZIP을 다운로드하고 **전체 압축을 풉니다**.
2. 압축을 푼 폴더에서 **CNSS.exe**를 실행합니다. Unity 설치는 필요 없습니다.
3. 실행 파일 옆의 `CNSS_Data`, `MonoBleedingEdge`와 DLL을 함께 보관하세요.

### Android

1. Android APK를 기기에 다운로드합니다.
2. 파일을 열고 설치합니다. 필요한 경우 다운로드에 사용한 앱에 ‘출처를 알 수 없는 앱 설치’를 허용합니다.
3. CNSS를 가로 화면으로 실행합니다.

Android 8.0 이상·ARM64 기기용입니다. Galaxy Tab S10 Ultra를 목표로 작업하고 있으며, 환경설정에서 전체 화면/휴대폰 비율, 드래그 감도, 조이스틱과 조작 버튼 크기·위치를 조정할 수 있습니다. 기존 GitHub APK와 같은 서명을 사용해 업데이트합니다. Play Store 설치본은 서명이 다를 수 있습니다.

## 기본 조작

| 행동 | Windows | Android |
| --- | --- | --- |
| 이동 | W A S D | 왼쪽 조이스틱 |
| 시점 | 마우스 이동 | 오른쪽 빈 공간 드래그 |
| 기본 행동: 문·서랍·집기·대화 | 마우스 왼쪽 버튼 | 행동 버튼 |
| 추가 행동: 물품 사용·문서 보기·기구 점검 | 마우스 오른쪽 버튼 | 사용 버튼 |
| 메뉴·환경설정 | F1 | 메뉴 |
| 프로토콜 확인 | F2 | 순서 |
| 동작 배속 | R | 배속 |

점프·달리기와 F3 시계·F4 책 단축키는 사용하지 않습니다. 시계가 필요한 계수 중에는 작은 시계가 자동 표시되고 이동이 잠깁니다. 술기 책은 휴게실 책장에서 읽습니다. 위치에 끼였을 때는 메뉴의 위치 복구를 사용하세요.

혈압 측정은 기본 행동으로 가압하고 추가 행동으로 감압을 시작합니다. 감압 중에는 기본 행동으로 속도를 1씩 높이고 추가 행동으로 1씩 낮춥니다. 맥박·호흡은 각각 **30초 계수 후 직접 ×2한 분당 값**을 기록합니다. 기구 작동 확인은 기구를 들고 추가 행동으로 진행합니다.

## 이번 버전의 주요 변경

- 물품 장면의 불필요한 손·팔 표시를 숨기고, 곡반 운반 거리와 확대 장면의 가시성을 조정했습니다.
- 체온계 탐침 덮개 장착, 귀 적용 방향과 베개 가림을 수정했습니다.
- 카트를 끌고 소개하러 가는 실제 안내와 손소독 중 자막을 수정했습니다.
- 팔을 침상에 받치는 움직임, 커프 밀착과 혈압 측정으로 이어지는 시점을 다듬었습니다.
- 30초 계수·기구 점검, 작은 자동 시계와 계수 중 이동 잠금을 반영했습니다.
- 물품 전용 동작의 보이지 않는 손 모델 생성, 팔 배열 할당과 안내 UI 중복 갱신을 줄였습니다.

## 확인 범위

PC의 변경 장면은 플레이어 카메라와 실제 동작·취소·재시작을 확인했습니다. 배포 파일의 시작과 기본 UI, Android 설치·기본 실행 결과는 해당 [릴리스 안내](https://github.com/itsmemanright/CNSS/releases/tag/v0.26)에 기록합니다. 모든 술기·모든 기기에서의 완전한 동작을 검증한 상태는 아닙니다. Galaxy Tab S10 Ultra/Fold 실물과 장시간 성능은 추가 확인이 필요합니다.
